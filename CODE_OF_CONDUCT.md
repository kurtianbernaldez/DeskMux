# Code of conduct

DeskMux contributors and maintainers must keep project spaces welcoming, respectful, and focused on the work. Harassment, threats, discriminatory language, deliberate intimidation, and publishing another person's private information are unacceptable.

Give technical feedback about the change rather than the person. Assume mistakes can be corrected, accept reasonable moderation, and avoid disrupting discussions or support channels.

Project maintainers may edit or remove contributions and restrict participation when behavior harms the community. Report conduct concerns privately through the repository owner's GitHub profile. Reports will be reviewed with care and kept private as far as reasonably possible.
