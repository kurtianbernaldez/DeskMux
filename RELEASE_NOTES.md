DeskMux 0.1.0 brings keyboard-driven sessions and nested panes to native Windows applications.

## Downloads

- **DeskMux-Setup-x64.exe** — recommended installer for Windows x64.
- **DeskMux-portable-x64.zip** — extract the complete folder; data stays beside the app.
- **DeskMux-update-x64.zip** — use About → Install downloaded update in DeskMux.
- **SHA256SUMS.txt** — checksums for the downloads.

## Features

Scoped pane guides, configurable themes, personalized shortcuts, shortcut recording and import/export, layout undo, drag-to-swap with a target preview, Alt-drag release, saved layout presets, app restoration, and monitor reconnect recovery.

Default shortcuts: press Ctrl+B and release, then F to float a pane or U to undo a layout change. Existing personalized prefixes remain unchanged.

## Known limitations

- Physical mixed-DPI docking configurations still need broader hands-on testing.
- Windows can deny foreground activation or management of elevated applications; DeskMux reports these failures.
- Undo history lasts for the current run and does not relaunch closed applications.
- Update checksums verify file integrity, not publisher identity. Use trusted download sources.

Automated validation covers pane geometry, persistence, shortcuts, update integrity, and isolated native Windows integration scenarios. Please report issues with the build information shown under About.
